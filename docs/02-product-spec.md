# 02. 제품 기획서 (가칭: 리프트로그 LiftLog)

> 01 분석을 바탕으로 한 **독자적인** 운동 루틴·기록 앱 기획서입니다. 개인용이며 판매하지 않습니다.

## 1. 한 줄 정의
"내 기구, 내 몸 상태에 맞춰 루틴을 짜 주고, 기록할수록 똑똑해지는 운동 일지."

## 2. 타깃 사용자
1. **헬스 입문자 (1년 미만)**: 무엇을 얼마나 해야 할지 모름 → 자동 루틴, 동작 설명이 필요.
2. **중급자 (1~3년)**: 루틴은 있지만 기록과 증량 관리가 귀찮음 → 빠른 기록, 다음 무게 추천이 필요.
3. **홈트족**: 덤벨, 밴드만 보유 → 기구 필터가 필요.

## 3. 핵심 차별점
1. **탭 한 번 RPE**: 세트 완료 버튼을 길게 누르거나 스와이프해서 난이도를 입력하면 다음 추천에 반영됩니다.
2. **콜드스타트 보정**: 온보딩에서 대표 종목의 무게를 입력받아 첫날부터 현실적인 추천을 줍니다.
3. **완전 로컬**: 서버 없이 폰 안에서만 동작합니다. 기록은 즉시 저장되고 파일로 백업하거나 내보낼 수 있습니다.
4. **부상 배려**: 불편한 부위를 고르면 해당 부위에 부담이 큰 종목을 제외하고 대체 종목을 제안합니다.

## 4. MVP 범위 (1차)

> ⚠️ 최신 범위와 로드맵은 [04-build-plan-planfit-base.md](04-build-plan-planfit-base.md)를 따릅니다.

| 영역 | 기능 |
|---|---|
| 온보딩 | 목표, 경력, 주당 횟수, 운동 시간, 보유 기구, 불편 부위, 대표 종목 무게(선택) |
| 루틴 | 자동 생성(분할 + 종목 + 세트/반복/휴식), 종목 교체, 순서 변경, 세트 추가/삭제, 직접 만들기 |
| 운동 진행 | 오늘의 운동, 세트 체크, 무게/횟수 수정, 지난 기록 표시, RPE 입력, 자동 휴식 타이머, 웜업 세트 |
| 라이브러리 | 종목 검색(부위/기구 필터), 동작 큐, 타깃 근육, 대체 종목 |
| 기록/분석 | 캘린더, 세션 상세, 종목별 추정 1RM 그래프, 주간 부위별 볼륨, 근육 회복도 |
| 동기부여 | 연속 기록(주 단위 목표 달성 기준), 레벨, 업적 |
| 데이터 | 계정 없음. 백업 파일(iCloud Drive/Google Drive에 저장), 복원, 내보내기(JSON/CSV) |

## 5. 화면 구조 (IA)

```
탭바
├─ 홈(오늘)
│   ├─ 오늘의 루틴 카드 → [운동 시작]
│   ├─ 주간 스트릭 / 이번 주 달성률
│   └─ 근육 회복도 미니맵
├─ 루틴
│   ├─ 내 프로그램 (자동 생성된 주간 분할)
│   ├─ 루틴 편집
│   └─ + 새 루틴
├─ (가운데) 운동 진행 화면  ← 운동 중일 때 플로팅 바로 상주
│   ├─ 종목 카드 리스트 (세트 행: 이전 기록 | 무게 | 횟수 | ✓)
│   ├─ 휴식 타이머 시트 (±15초, 건너뛰기)
│   └─ 종료 → 요약(총 볼륨, PR, 소요 시간)
├─ 기록
│   ├─ 캘린더
│   ├─ 통계 (1RM, 볼륨, 빈도)
│   └─ 종목별 히스토리
└─ 프로필
    ├─ 신체 정보 / 목표 / 기구 재설정
    ├─ 단위(kg/lb), 기본 휴식 시간
    └─ 백업, 내보내기, AI 모델 관리
```

## 6. 핵심 사용자 흐름

### 6.1 온보딩 → 첫 운동 (목표: 2분 이내)
1. 목표 선택 → 2. 경력 → 3. 주 몇 회 / 몇 분 → 4. 운동 장소(헬스장/집) 및 기구 체크 → 5. 불편한 부위(선택) → 6. 대표 종목 무게(선택, 건너뛰기 가능) → 7. 생성된 프로그램 미리보기 → 8. 오늘 운동 시작

### 6.2 세트 기록
- 기본값: 추천 무게와 반복 수가 미리 채워져 있습니다. ✓ 탭 → 완료(RPE=적당으로 기록) → 휴식 타이머가 자동 시작됩니다.
- ✓ 길게 누르기 → 쉬움 / 적당 / 힘듦 / 실패 선택.
- 값을 수정하면 이후 세트에도 일괄 반영할지 묻습니다.


## 7. 참고 사항
- 경쟁 앱의 상표, 루틴 콘텐츠, 영상, 이미지를 사용하지 않습니다. 운동 종목명과 일반적인 운동 과학 원리는 공용 지식입니다.
- 의료 서비스가 아니라는 고지와 통증 시 중단 안내를 넣습니다.
- 개인용이므로 스토어 출시 없이 개발 빌드로 내 폰에만 설치합니다.
