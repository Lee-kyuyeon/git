## 3. 기능별 역설계 (구현 추론)

### 3.1 자동 루틴 생성 (플랜핏, 데일리핏)
- **입력**: 목표(근비대/근력/다이어트/건강), 경력, 주당 횟수(2~6), 1회 운동 시간(30~90분), 보유 기구, 불편한 부위.
- **추론한 구조**: 규칙 기반 생성기가 먼저 동작하고, "AI"는 개인화 가중치 조정 단계일 가능성이 높습니다.
  1. 주당 횟수 → **분할 방식 결정**(2~3회: 전신, 4회: 상/하체, 5~6회: 푸시/풀/레그).
  2. 각 운동일의 **타깃 부위 슬롯** 정의(예: 푸시 = 가슴 2, 어깨 1, 삼두 1).
  3. 종목 DB를 **기구 × 부상 부위 × 난이도**로 필터링.
  4. 슬롯마다 컴파운드 종목을 먼저, 고립 종목을 뒤에 배치.
  5. 시간 예산 = Σ(세트 × (수행 시간 + 휴식)) 로 종목 수를 자릅니다.
  6. 목표별 **세트/반복/휴식 템플릿**을 적용합니다(근력 3~5회, 근비대 8~12회, 다이어트 12~15회 + 짧은 휴식).
- 플랜핏 리뷰의 "첫 추천 무게가 너무 낮다"는 문제 → 기록이 없을 때 쓰는 **보수적 기본값(콜드스타트)** 때문입니다. 첫 세션 이후 기록 기반으로 보정합니다.

### 3.2 다음 무게/횟수 추천 (짐워크, 데일리핏)
- **추론**: 더블 프로그레션 + RPE 보정.
  - 모든 세트가 목표 반복 상한에 도달하고 RPE ≤ 8이면 → 무게 증가(상체 +2.5kg, 하체 +5kg, 덤벨 +2kg).
  - 하한에 미달하거나 RPE ≥ 9.5이면 → 무게 유지 또는 −5~10% 디로드.
  - 그 사이면 → 같은 무게로 반복 +1을 목표로 합니다.
- 1RM 추정은 Epley `w × (1 + r/30)` 또는 Brzycki 공식을 쓰는 것으로 보입니다.

### 3.3 근육 회복도 (짐워크 PRO)
- **추론**: 부위별 마지막 자극 시각과 볼륨으로 피로를 계산하고, 시간이 지나며 회복되는 모델입니다.
  `fatigue = Σ volume_i × exp(-Δt_i / τ)`, τ ≈ 24~48h(부위 크기별). 이를 0~100% 회복도로 정규화해 인체 맵 히트맵으로 보여줍니다.

### 3.4 정체기 분석 / 1RM 리포트 (데일리핏 PRO)
- 종목별 추정 1RM 시계열에서 최근 N주 기울기가 0 이하이면 정체로 판정하고, 볼륨/강도/종목 변경을 제안합니다.

### 3.5 게이미피케이션
- 연속 기록(스트릭), 레벨(누적 볼륨/세션 경험치), 업적을 제공합니다. 데일리핏은 "연속 기록 보호권"을 구독 혜택으로 줘서 **유지율과 과금을 연결**합니다.

## 4. 사용자 페인 포인트 → 우리의 기회

| 페인 포인트 (리뷰 근거) | 앱 | 대응 |
|---|---|---|
| 첫 추천 무게/세트가 너무 낮음 | 플랜핏 | 온보딩에서 주요 종목 "최근 수행 무게"를 선택 입력받아 콜드스타트 보정 |
| 체감 난이도 기반 자동 조절 요청 | 플랜핏 | 세트마다 탭 한 번으로 RPE(쉬움/적당/힘듦/실패) 입력 → 추천 반영 |
| 메모/기록 소실 | 플랜핏 | **로컬 우선 저장 + 동기화** (오프라인에서도 손실 없음) |
| 기기 변경 후 로그인/계정 복구 실패 | 플릭 | 계정 연결 다중화, 익명 → 소셜 계정 승격, 내보내기(JSON/CSV) |
| 동작 설명 부족 (정지 이미지) | 플릭 | 종목마다 단계별 큐, 흔한 실수, 타깃 근육 표시 |
| 웜업/쿨다운 루틴 부재 | 플릭 | 루틴 앞뒤 자동 웜업 세트(작업 중량의 40/60/80%) |
| 핵심 기능이 비싼 유료에 묶임 | 짐워크, 플랜핏 | 기록, 추천, 타이머는 **무료**, 분석/AI 코치만 유료 |

## 5. 비즈니스 모델 시사점
- 가격대는 두 갈래입니다. **프리미엄(월 1만원대: 플랜핏, 짐워크)** 과 **저가(월 4~5천원: 플릭, 데일리핏)**.
- 여러 가격 플랜(A/B/C/D)과 "대상자 전용" 상품은 **가격 A/B 테스트와 윈백 할인**을 활발히 한다는 뜻입니다.
- 연간 플랜이 월간 대비 50~60% 할인되어 있어 연간 전환을 유도합니다.
- 제안: 월 ₩4,900 / 연 ₩34,900 / 7일 무료 체험. 기록은 무료로 두어 이탈 장벽을 낮춥니다.
