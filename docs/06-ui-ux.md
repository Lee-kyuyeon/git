# 06. UI/UX 설계

## v2 개편: "플랜핏 같다" 피드백 반영 → 게임·성장형 + 도감

| 영역 | v1 (플랜핏식) | v2 (LiftQuest) |
|---|---|---|
| 정체성 | 오늘의 루틴 카드 → 시작 | **근육마다 레벨업**하는 퀘스트 게임 |
| 온보딩 | 한 화면에 질문 하나 (8단계) | **캐릭터 생성** 4화면: 클래스 → 훈련 일정 → 몸 상태 → 첫 퀘스트 |
| 홈 | 오늘의 운동 + 스트릭 + 회복도 | 플레이어 카드(레벨·랭크) + 오늘의 미션(퀘스트 기여도) + **주간 퀘스트** |
| 운동 중 | 기록 | 기록 + **세트마다 +XP**, ⓘ로 가이드 |
| 완료 | 시간·볼륨·PR | **획득 XP, 부위 레벨업, 퀘스트·업적 달성** |
| 정보 | 동작 포인트 몇 줄 | **운동 도감**(66종: 근육 지도, 주동근·보조근 해부학명, 자극 위치, 준비·동작·호흡, 흔한 실수, 내 기록, 대체 종목) + **근육 도감**(16부위: 해부학명, 구성, 하는 일, 자극 요령, 이 근육을 키우는 종목) |
| 디자인 | 매끈한 다크 + 주황 | **굵은 테두리·단단한 그림자의 게임 카드**, 보라 + 골드(XP) |

게임 규칙은 근거와 맞물려 있습니다.
- XP = 부위별 유효 세트 (주동근 10, 보조근 5, RPE 7 미만은 절반) → 주간 볼륨과 같은 단위
- 부위 퀘스트 목표 = 루틴 생성기의 근거 기반 주간 목표 세트 → 퀘스트를 깨면 권장 볼륨을 채운 것
- 주간 클리어 = 출석 + 부위 퀘스트 4개 / 업적에 "불편 부위를 가볍게 10세트" 같은 현명한 행동 포함

## 운동 화면 안내 보강 (v2.3) — 실사용 피드백 "어떻게 하는지 모르겠고 추천 무게도 없다"
- **추천 시작 무게**: 첫 기록이 없어도 체중(선택 입력, 없으면 성별 평균)·경력·목표 반복으로 시작 무게를 제안 (`core/src/startWeight.ts`). 초보자 기준 보수적 비율표 + Epley 반복 보정, 바벨은 최소 20kg. 체감 난이도로 다음 세션부터 자동 보정
- **무게 단위 표시**: kg (한 손) / kg (덤벨 1개) / 추가 kg(맨몸)
- **종목 카드 안 설명**: 주동근·보조근, 강도를 쉬운 말로("마지막 2회가 힘들게"), "❓ 어떻게 해요?"(준비·동작·자극·피할 점), "🧍 자세히 (3D·영상)" 버튼. 첫 운동에서는 첫 종목 설명이 펼쳐진 상태
- **첫 운동 사용법 카드**: 무게 확인 → ✓ → 휴식 → 다음 세트, 길게 눌러 난이도
- 업데이트 전에 0kg로 만들어진 진행 중 운동은 열 때 추천 무게로 자동 채움

## 기구 선택 개편 (v2.2)
- 기구를 9종 → **20종**으로 세분화: '머신' 하나였던 것을 레그 프레스·핵 스쿼트·레그 익스텐션·레그 컬·힙 머신·카프 머신·체스트 프레스·숄더 프레스·펙덱·로우 머신으로 나누고, 스쿼트 랙·딥스대·랫 풀다운을 추가
- 기구마다 **자체 제작 SVG 일러스트**, 분류별(프리웨이트 / 맨몸·소도구 / 케이블 / 하체 머신 / 상체 머신) 카드 그리드, 분류별 모두 선택
- 프리셋: 헬스장 / 작은 헬스장 / 집 / 맨몸만, 고를 때마다 **할 수 있는 운동 수** 표시
- 종목 상세에 필요한 기구를 그림으로 표시
- 예전 설정('machine')은 자동으로 개별 기구로 이전
- '내 자세 영상' 기능은 제거 (남은 영상은 자동 정리)

## 경량화 (v2.1)

| 항목 | 이전 | 이후 |
|---|---|---|

## v1: 4개 앱의 장점 조합

> 각 앱의 **사용 흐름과 상호작용 패턴**만 가져왔고, 화면 디자인·색·아이콘·문구는 독자적으로 만들었습니다.
> 구현: `app/` (Vite + React PWA). 화면 크기 기준: iPhone 16 Pro (393×852).

## 2. 디자인 원칙
1. **엄지 영역**: 주요 버튼은 화면 아래쪽. 세트 완료 버튼은 오른쪽 끝 40px 이상.
2. **운동 중 최소 입력**: 기본 상태에서 세트당 탭 1번. 추가 입력(난이도, 메모)은 길게 누르기나 시트로.
3. **다크 기본**: 헬스장 조명과 배터리를 고려. 라이트 모드 자동 지원.
4. **색의 의미 고정**: 주황 = 행동(시작, 완료), 초록 = 끝난 세트·회복됨, 노랑 = 주의(웜업, 불편 부위, 회복 중), 빨강 = 피로·삭제.
5. **오프라인 우선**: 모든 데이터는 기기(IndexedDB)에 즉시 저장, 앱을 닫았다 열어도 진행 중 운동이 이어짐.

## 3. 검증
Playwright로 iPhone 16 Pro 화면 크기에서 다음 흐름을 자동 실행해 확인했습니다(콘솔 오류 0건).

온보딩 8단계 → 홈 → 운동 시작 → 소수점 무게 입력(62.5)과 남은 세트 자동 반영 → 세트 완료와 휴식 타이머 → 길게 눌러 난이도 → 메모 저장 → 대체 종목 시트 → 운동 완료와 강도 피드백 → 루틴/기록/나 탭 → 새로고침 후 데이터 유지 → 같은 날 재시작 시 메모·지난 기록·추천 무게 표시 → 라이트 모드.

## 4. 아직 없는 것
- 종목 동작 일러스트·영상 (현재는 요령 텍스트)
- 인체 그림 형태의 회복도 맵 (현재는 격자)
- 운동 후 강도 피드백을 다음 세션 세트 수에 반영하는 로직
- 기록 공유 이미지, 유산소 기록
